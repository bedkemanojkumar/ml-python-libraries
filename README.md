# Python and Machine Learning Libraries

This repository contains my practical learning notes, examples, and experiments while developing a foundation in Python, Data Science, and Machine Learning.

The purpose of this repository is to understand the libraries through implementation and experimentation rather than only memorizing syntax.

## Topics Covered

* Python programming fundamentals
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Data cleaning
* Exploratory data analysis
* Basic numerical computing
* Machine learning preparation

## Repository Structure

```text
├── basics/
├── numpy/
├── pandas/
├── matplotlib/
├── seaborn/
└── requirements.txt
```

## Learning Approach

For each library, I try to include:

1. Basic syntax
2. Practical examples
3. Important functions
4. Small experiments
5. Notes about common mistakes
6. Applications in machine learning

## Status

This repository is continuously updated as I learn and practice new concepts.
